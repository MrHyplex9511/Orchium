# Orchium Docs

Orchium is the open source AI coding agent. These pages cover the core
concepts you need to get productive.

## Getting Started

- **[Installation](../README.md#installation)** — package manager installs, desktop app
- **[Agents](./agents.md)** — the built-in `build`, `plan`, and `general` agents, and how to configure your own
- **[Configuration](./configuration.md)** — the `orchium.json` config file, providers, and permissions

## Key Facts

- **Config file**: `orchium.json` (project) or `~/.config/orchium/orchium.json` (global)
- **Default agent**: `build` (full-access)
- **Switch agents**: `Tab` key
- **Independent fork**: Orchium is a fork of OpenCode under the MIT License; it is not affiliated with the original project.
